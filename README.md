# skills-apis

**Design e construção de APIs** — HTTP, autenticação, validação e boas práticas.

</div>

## 📋 Sobre

Estudos práticos de desenvolvimento de APIs: estrutura de rotas, validação de payloads, formatos de erro e versionamento.

## 📂 Conteúdo

- `server.js` — API funcional com Express
- `src/routes.js` — handlers de rotas
- `src/validate.js` — middleware de validação
- `examples/` — client HTTP (`client.js`), tabela de status codes
- `api-design.md` / `versioning.md` — guias de design

## 🚀 Quick start

```bash
npm install
npm start   # API em http://localhost:3000
```
